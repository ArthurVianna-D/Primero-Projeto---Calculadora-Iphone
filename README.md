Olá, este é o meu primeiro projeto: Uma réplica da calculadora do iPhone desenvolvida com HTML.

O objetivo desse projeto é para que eu consiga praticar lógica de programação básica e estruturação de interfaces inspiradas em aplicações reais, no caso, um app já existente do IOS.

1° O conteúdo contém:
- Interface inspirada na calculadora do iPhone
- Operações básicas:
  - Adição (+)
  - Subtração (-)
  - Multiplicação (×)
  - Divisão (÷)
- Botão AC (limpar)
- Resultado com "="
- Layout visual semelhante ao app original.

2° Linguagem:
- HTML
